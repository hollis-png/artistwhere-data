# 繪師去哪了：公開資料

大家一起維護的繪師跨平台帳號資料庫：補連結、查失效、找轉生。
網站：https://artistwhere.com/

## 內容
`artists/<前兩碼>/<id>.json`，每位繪師一檔：名稱、類型、活動，以及各平台連結與狀態（`alive` 活著／`dead` 失效）。
不含使用者資料、收藏、頭像圖片、待確認的連結。

## 怎麼貢獻
- **補充、更正或新增**：開 Issue，貼上繪師名稱與公開帳號網址，審核後由維護者補進網站。
- **請不要直接開 Pull Request 改 `artists/`**：這個資料夾每天由網站自動覆蓋，PR 的修改會被蓋掉。
- `validate.mjs` 是匯出時的驗證腳本（網址格式、重複、內網位址、含密鑰參數、狀態值）。
- 只放繪師**自己公開**的帳號；請勿放私人帳號、住址、聯絡方式或任何個資。

## 審核與同步
網站為主，每天自動單向匯出到本 repo（覆蓋 `artists/`）；這裡的任何修改都不會寫回網站。Issue 經人工審核後補進網站，隔天就會出現在這裡。

## 下架
繪師本人或相關權利人要求移除，開 Issue 說明即可，確認後會從資料集與網站移除。
