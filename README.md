# 繪師去哪了：公開資料

大家一起維護的繪師跨平台帳號資料庫：補連結、查失效、找轉生。
網站：https://artistwhere.com/

## 內容
`artists/<前兩碼>/<id>.json`，每位繪師一檔：名稱、類型、活動，以及各平台連結與狀態（`alive` 活著／`dead` 失效）。
不含使用者資料、收藏、頭像圖片、待確認的連結。

## 怎麼貢獻
- **補充或更正連結**：開 Pull Request 修改該繪師的 JSON，或開 Issue 貼上繪師名稱與網址。
- **新增繪師**：新增一個 JSON（`id` 用 `artist_` 加英數字，不可與現有重複）。
- 投稿前先跑 `node validate.mjs`；CI 也會自動檢查（網址格式、重複、內網位址、含密鑰參數、狀態值）。
- 只放繪師**自己公開**的帳號；請勿放私人帳號、住址、聯絡方式或任何個資。

## 審核與同步
PR 經人工審核合併後，才會匯入網站；這裡不會直接寫入正式站。
網站為主、定期匯出到本 repo，因此匯出會覆蓋 `artists/`：已合併的貢獻會先匯入網站，再出現在下一次匯出。

## 下架
繪師本人或相關權利人要求移除，開 Issue 說明即可，確認後會從資料集與網站移除。
